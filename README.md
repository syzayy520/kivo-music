# Kivo Music

Kivo Music is a flagship desktop-first music player concept built around Apple Music-level visual order, local music ownership, lyrics-first listening, strong queue/search foundations, and a maintainable feature-first architecture.

This repository is being initialized with strict product and engineering rules:

- One feature, one folder.
- One folder, one responsibility.
- One file, one responsibility.
- Pages only wire and compose features.
- Mock data, copy, types, state, and styles stay separated.
- No temporary architecture.
- No oversized page dumping.
- Playback must be represented by Kivo Playback Core boundaries, not direct UI coupling.

## Direction

Kivo Music is not an Apple Music clone. It is an original premium local music player inspired by Apple Music's content order, Plexamp's library reactivation, Doppler's local ownership simplicity, Roon's library depth, Audirvana's audio-quality seriousness, and MusicBee / foobar2000 / AIMP's long-term playback power.
